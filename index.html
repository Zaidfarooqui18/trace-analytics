< 3 KB Interaction Tracker

Standalone vanilla JavaScript tracking script that collects page views, clicks, rage clicks, and screen viewports without framework dependencies or site slowdowns.

🗺️

Normalized Click Heatmaps

Canvas-rendered click heatmaps in Blobs, Point Dots, and Grid Density modes. Coordinate normalization guarantees accuracy across mobile, tablet, and desktop viewports.

⏱️

Chronological User Journeys

Trace visitor sessions step-by-step from landing page to checkout. Includes Session Replay-Lite visual playback and frustration rage-click markers.

📊

Sessions Explorer & CSV Export

Filter sessions across 24h, 7d, 30d, or All-Time. Search by UUID, filter by device, and export the complete filtered result set as clean UTF-8 CSV spreadsheet files.

Live Full-Stack Deployment on Vercel

Trace Analytics consists of a React 18 Dashboard, a Node.js Express REST API, and a MongoDB Database. While GitHub Pages serves static files (like this portal and the Demo Store), full-stack data ingestion and session aggregation run natively on Vercel with serverless functions!

# Deploy to Vercel in 60 seconds: 1. Import repository on vercel.com 2. Framework Preset: Vite 3. Root Directory: ./ (monorepo root) 4. Add Environment Variable: MONGODB_URI = your-mongodb-atlas-uri 5. Click Deploy!
